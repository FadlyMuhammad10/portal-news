# Portal News

Website portal berita yang dikembangkan menggunakan Go. Proyek ini ditujukan
sebagai tempat untuk menyajikan berita dan informasi secara online.

## Teknologi

- [Go](https://go.dev/)

## Pengembangan

Pastikan Go sudah terpasang, lalu clone repository dan masuk ke direktori
proyek:

```sh
git clone <URL-repository>
cd portal-news
```

Detail cara menjalankan aplikasi akan ditambahkan setelah fitur dan konfigurasi
aplikasi tersedia.
